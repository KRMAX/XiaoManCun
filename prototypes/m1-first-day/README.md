# 小满村 · 春一日（M1 tile 世界原型）

横屏 16:9 的**真·瓦片世界**可玩原型。这一版从「插画当背景 + canvas 贴纸」彻底换成了**星露谷式的 tile/精灵引擎**：可走的瓦片地面、跟随相机、4 向逐帧行走的农夫、**自由游荡的动画小鸡**、动画水塘，以及**长在真实耕地里、分阶段成长的作物**。

> 界面层和 Canvas 运行时精灵已接入 `assets/pixel-packs/xiaomancun-initial-style` 的初始风格像素包：首屏小院、HUD、提示条、外婆头像、按钮、地砖、老屋、鸡舍、角色、小鸡和作物样式统一到浅草绿、奶油木色、柔棕描边方向。

## 打开方式

必须用本地 HTTP 打开（直接双击会因相对路径 + 跨域取像素失败）：

```bash
# 仓库根目录
python3 -m http.server 8123
# 浏览器访问
# http://localhost:8123/prototypes/m1-first-day/index.html
```

## 操作

- **移动**：点地面走过去（相机跟随，可在院里自由走动）；或键盘 **WASD / 方向键**。
- **种田**：走到田边、靠近耕地后**点土地**：空地→播种 → 再点→浇水 → 睡一觉长一级 → 成熟后点击收获。
- **进屋（星露谷式 Portal）**：走到**老屋门口**会自动**淡入淡出切到室内**；屋里点**床**睡觉、点**柜子**查看；走到室内**门口**自动出屋。**切场时全局时间与农场状态不丢**。
- **睡觉**：在室内点床（或室内右下角按钮）跨天，**浇过水**的作物成长一级。
- **鸡**：在鸡舍场地里自由游走、踱步、idle，纯氛围。
- 顶部时钟随实时流逝、**跨场景持续**，体现星露谷"时间一直在走"。

## 这一版相比上一版，根本变化

| | 上一版（被否） | 这一版 |
| --- | --- | --- |
| 地图 | 一张烤死的设计插画当背景 | **瓦片拼的世界**，可走、可遮挡、相机跟随 |
| 角色 | canvas 画的矢量小人 | **真·精灵图集 4 向逐帧行走**（小满村初始风格像素包） |
| 鸡 | 无 / 形状 | **精灵动画小鸡**，闲逛 AI 自由移动 |
| 作物/土地 | 菱形 + 文字标签 | **真实耕地瓦片 + 分阶段成长作物精灵** |

## 与正式 Cocos 工程的映射（见 `docs/design-tables/scene-system-architecture.md`）

| 原型 | 正式落点 |
| --- | --- |
| 瓦片地图 + 可行走判定 + 相机 | `TiledMap` + 可行走遮罩 + `CameraFollow` |
| 角色 4 向逐帧 + 点地/键盘移动 | 角色精灵 `Animation` + `CharacterController` + `PathMover` |
| 鸡闲逛 AI | `CreatureSystem` / `AmbientCreature` |
| 耕地/作物分阶段 + 浇水 + 跨天成长 | `FarmSystem` + `crop.json` 配表（服务端权威结算） |
| 深度排序（脚底 y） | 统一 y 排序 siblingIndex |

## 星露谷式场景制（本版新增）

- **两张独立地图**：`院子(out)` 与 `老屋内(in)`，用门口 **Portal**（走过去触发）+ 淡入淡出切换——这正是星露谷/仙剑通用的 warp 模型。
- **全局状态跨场景持续**：时间时钟、天数、现金、农田作物状态都是全局的，进屋/出屋不重置；作物按"天"（睡觉）成长，符合星露谷"时间一直在走、作物按日成长"。
- 室内：程序化像素地板/墙 + 像素床（睡觉）与**柜子**（仓库占位对话）。

## 已知简化 / 待办

- **运行时美术已换新**：`assets/xiaomancun/` 是从「小满村初始风格像素包」裁出的原型运行时素材，兼容旧 Sprout 文件接口。
- **室内仍简化**：室内地板/墙和床仍是程序化像素绘制，后续可替换成正式室内 tile sheet。
- 地面用自动挑选的「纯草 / 纯耕地」瓦片满铺，未做 autotile 边缘过渡；正式版用 Tiled 自动过渡。
- 作物成长为演示压缩（浇水 + 睡觉，每天 +1 级，5 级成熟）；正式以 `crop-values.md` 为准。
- NPC 作息（外婆在不同场景按时间出现）尚未做，是更像星露谷的下一步。
- 音效为占位蜂鸣。

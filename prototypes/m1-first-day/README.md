# 小满村 · 春一日（M1 手绘地图数据层原型）

横屏 16:9 的**小满村可玩原型**。当前版本明确采用“手绘大地图 + 不可见数据层 + 同画风动态精灵”的规则：画面保持高细节手绘/预渲染底图，移动、碰撞、交互、动物区和作物状态仍由数据层驱动。

> 目标是玩起来像星露谷，但画面不硬套低清像素瓦片；村子看起来应像一张完整的手绘地图。

## 打开方式

必须用本地 HTTP 打开：

```bash
# 仓库根目录
python3 -m http.server 8123
# 浏览器访问
# http://localhost:8123/prototypes/m1-first-day/index.html
```

调试时可以跳过首页：

```text
http://localhost:8123/prototypes/m1-first-day/index.html#go
```

## 操作

- **移动**：点地面走过去，或用 **WASD / 方向键**。
- **交互**：点房子、鸡舍、菜地、村务牌、NPC、鸡，角色会先走到站立点再弹对话。
- **相机**：跟随角色在村子主地图内移动。

## 视觉与地图规则

- `map-data.js` 是地图数据源，默认地图是 `XMC_MAPS.village`。
- `village` 使用 `engine: 'painted-data-layer'`。
- 地图背景是 `assets/scenes/village.png`，坐标使用原始图片像素坐标。
- 可走区域用 `navigation.walkBoundary` 描述，屋体、鸡圈棚体、池塘、菜地等阻挡用 `navigation.blockedAreas` 描述。
- 鸡圈、屋门、菜地、池塘、作坊和村口仍是 `objects.interact` / `portals` 数据点，不额外盖低清像素物件。
- 主角已切到 `assets/painted/` 的手绘帧图，按底图的光影和透视重做。
- 后续作物、动物、NPC 都应按同一规则补：动态素材要匹配手绘底图，而不是复用硬像素贴纸。

## 当前实现重点

| 模块 | 当前做法 |
| --- | --- |
| 地图 | 连续户外村子主地图，外婆院子、田地、鸡圈、邻居屋、作坊、池塘都在同一张手绘图内 |
| 图层 | 手绘底图 + 不可见可走/碰撞/交互数据层 + 动态实体层 |
| 移动 | 点击寻路与键盘移动共用手绘地图数据层碰撞 |
| 人物 | 主角切到手绘动态帧，按脚底 y 排序 |
| 鸡圈 | 使用手绘地图里的鸡圈本体，只保留碰撞和交互热点 |
| 动物/作物 | 这次先收敛视觉规则；后续需要按手绘风格重做动态鸡、作物和 NPC |

## 后续步骤

1. 按手绘风格补动态鸡、鸭、NPC，而不是复用低清像素素材。
2. 作物状态层改为同画风的小植物覆盖层，保留锄地、播种、浇水、成熟和收获数据。
3. 外婆、村民、动物 AI 接回 `entities`，但资产必须统一光影和比例。
4. 对 `navigation.walkBoundary` / `blockedAreas` 继续微调，保证手绘图上的可走区更自然。
5. 增加屋内地图和村口传送。

## 素材说明

- 运行底图来自 `assets/scenes/village.png`。
- 手绘主角帧位于 `assets/painted/`。
- `assets/xiaomancun/` 仍保留为历史像素素材和临时图标来源，但不再作为默认视觉方向。

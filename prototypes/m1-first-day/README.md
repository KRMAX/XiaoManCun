# 小满村 · 春一日（M1 分层瓦片原型）

横屏 16:9 的**小满村可玩原型**。当前版本已从“整张手绘背景 + 角色叠层”改成更接近星露谷的运行方式：瓦片地图、对象、人物、动物、植物分别作为数据层进入游戏。

> 首页、HUD、对话框仍沿用初始设计风格；场景内部开始改为真正可玩的分层结构。

## 打开方式

必须用本地 HTTP 打开：

```bash
# 仓库根目录
python3 -m http.server 8123
# 浏览器访问
# http://localhost:8123/prototypes/m1-first-day/index.html
```

调试时可以跳过首页：

```text
http://localhost:8123/prototypes/m1-first-day/index.html#go
```

## 操作

- **移动**：点地面走过去，或用 **WASD / 方向键**。
- **交互**：点房子、鸡舍、菜地、村务牌、NPC、鸡，角色会先走到站立点再弹对话。
- **相机**：跟随角色在村子主地图内移动。

## 地图数据层

- `map-data.js` 是地图数据源，默认地图是 `XMC_MAPS.village`。
- `village` 使用 `engine: 'layered-tilemap'`。
- 地图规格：`80 x 52` 个瓦片，每个瓦片 `16 x 16`，运行时放大 2 倍。
- 地面由 `terrain.base` 和 `terrain.patches` 组成：草地、泥路、石板、耕地、水体。
- 建筑、鸡舍、树、栅栏、水井、村务牌放在 `objects`。
- 作物放在 `cropBeds`，按格子渲染，后续可接成长状态。
- 人物和动物放在 `entities`，鸡已经有简单活动范围。
- 建筑门口和村口放在 `objects.interact` / `portals`，不是画死在背景里。

## 当前实现重点

| 模块 | 当前做法 |
| --- | --- |
| 地图 | 连续户外村子主地图，外婆院子、田地、鸡舍、邻居屋、作坊、池塘都在同一张地图内 |
| 图层 | 草地/道路/水体/耕地瓦片层 + 作物层 + 对象层 + 实体层 |
| 移动 | 点击寻路与键盘移动共用瓦片碰撞、对象碰撞、水体碰撞 |
| 人物 | 主角、外婆、作坊 NPC 作为实体渲染，按脚底 y 排序 |
| 动物 | 鸡作为实体渲染，在鸡舍围栏范围内简单游走 |
| 植物 | 菜地按作物格渲染，不再是背景贴图 |

## 后续步骤

2. 扩充对象素材：树、井、牌子、栅栏目前有部分程序化绘制，需要替换成统一像素素材。

4. 做动物 AI：喂食、回窝、产蛋、日夜状态。
5. 做作物状态：空地、翻土、播种、浇水、成长、成熟、收获。
6. 增加屋内地图和村口传送。

# 小满村 · 春一日（M1 手绘场景原型）

横屏 16:9 的**手绘小院背景 + 地图数据层 + Canvas 角色叠层**可玩原型。当前重点是先把原型图上的可走区域、碰撞物、交互热点和点击寻路整理成数据，方便继续校准手感。

> 界面层和 Canvas 运行时精灵已接入 `assets/pixel-packs/xiaomancun-initial-style` 的初始风格像素包：首屏小院、HUD、提示条、外婆头像、按钮、地砖、老屋、鸡舍、角色、小鸡和作物样式统一到浅草绿、奶油木色、柔棕描边方向。

## 打开方式

必须用本地 HTTP 打开（直接双击会因相对路径 + 跨域取像素失败）：

```bash
# 仓库根目录
python3 -m http.server 8123
# 浏览器访问
# http://localhost:8123/prototypes/m1-first-day/index.html
```

## 操作

- **移动**：点地面走过去（相机跟随，可在院里自由走动）；或键盘 **WASD / 方向键**。
- **交互热点**：点菜地、池塘、鸡舍、屋门、院门、石桌后，角色会先走到对应站立点再弹说明对话。
- 顶部时钟随实时流逝、**跨场景持续**，体现星露谷"时间一直在走"。

## 地图数据层

- `map-data.js` 是当前地图数据源，坐标统一使用每张背景图自己的原始像素坐标。
- `XMC_MAPS.village` 现在是默认运行地图，背景为 `assets/scenes/village.png`，尺寸 `1536 x 1024`。
- `XMC_WORLD.maps.village` 描述正式方向上的**小满村连续户外主地图**：院子、村道、邻居屋群、作坊、池塘河沟、小广场都在同一张村子地图里自由移动。
- 旧的 `XMC_MAPS.courtyard` 保留为 `village / grandma-yard` 的切片数据，用来对照和回退。
- `navigation.walkBoundary` 描述院子可行走外轮廓。
- `collision` 描述鸡舍棚体、石桌、水井、池塘、菜地、工具棚等阻挡区。
- `hotspots` 描述交互区域、角色站立点和对话文案。
- `effects` 描述池塘水波和桃花飘落的锚点。
- `game.js` 只负责加载数据、寻路、碰撞、输入和绘制；后续调地图优先改 `map-data.js`。

## 地图切换原则

- **不切图**：村内户外移动，例如外婆院子、村道、邻居门口、池塘、作坊、小广场，应该在 `village` 主地图里连续行走。
- **切图**：进入建筑室内、去县城、进山/河滩等远距离区域、进入剧情副本，才使用新的地图关卡。
- 当前已经补了 `village.png` 主地图底图：左下角是外婆家院子区域，往外连接村道、作坊、邻居屋群、小广场、石桥和河沟。

## 当前实现重点

| 模块 | 当前做法 |
| --- | --- |
| 地图 | 默认运行 `village` 连续户外主地图，外婆院子嵌在左下家园区 |
| 点击移动 | 在隐藏网格上做轻量 A* 寻路，避免从菜地直线撞到石桌或鸡舍 |
| 角色 | 复用小满村初始风格精灵图，按目标点移动和朝向切帧 |
| 交互 | 热点区域和站立点由 `map-data.js` 配置，触发后播放对应说明对话 |

## 与正式 Cocos 工程的映射（见 `docs/design-tables/scene-system-architecture.md`）

| 原型 | 正式落点 |
| --- | --- |
| 手绘背景 + 地图数据层 + 相机 | `TiledMap` 或场景底图 + 可行走遮罩 + `CameraFollow` |
| 角色 4 向逐帧 + 点地/键盘移动 | 角色精灵 `Animation` + `CharacterController` + `PathMover` |
| 热点与传送门 | `Interactable` / `Portal` 配表 |
| 点击寻路 | `PathMover` + 可行走遮罩 |
| 深度排序（脚底 y） | 统一 y 排序 siblingIndex |

## 已知简化 / 待办

- 当前只有院子一张场景，屋内、村道、县城还只是热点文案占位。
- 碰撞框和热点是按原型图目测描点，后续可以继续微调。
- 菜地、鸡舍、池塘现在只是交互说明，还没接正式种植/养殖系统。
- NPC 作息（外婆在不同场景按时间出现）尚未做，是更像星露谷的下一步。
- 音效为占位蜂鸣。

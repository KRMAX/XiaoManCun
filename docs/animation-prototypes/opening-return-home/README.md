# 《小满村》开场过场动画原型

> ⚠️ 方向变更说明：项目已确定首发为**横屏 16:9**（见 `docs/design-tables/ui-flow.md`）。
> 本原型当前仍为 9:16 竖屏版本，**需按横屏 16:9 重新分镜与适配**（关键帧裁切/重绘、字幕与控件位置、镜头横向运动）。在重做前，本原型仅作竖屏节奏参考。

这是一个可直接打开的 HTML 动画原型，用于验证“都市疲惫 -> 决定返乡 -> 抵达小满村 -> 开始春一日”的开场节奏。

## 当前版本内容

- 形式：微信小游戏内实时过场动画原型，不依赖视频播放器。
- 比例：9:16 竖屏。
- 时长：约 94 秒。
- 表现：关键帧背景、镜头推拉、场景淡入淡出、字幕、语音/广播/对白样式、环境音原型、中文语音播报、进度条、声音开关、播放/暂停/重播/跳过。
- 素材：3 张新生成开场关键图 + 6 段复用现有小满村概念图。

## 声音原型

- 背景音：用 Web Audio 合成雨声、城市低频、车内低频、风声、河流声、鸟鸣和轻音乐点缀。
- 说话声：用浏览器 `speechSynthesis` 中文语音播报当前对白。
- 限制：浏览器通常禁止自动播放声音，第一次需要点击“声音关/声音开”按钮授权。
- 后续正式版本：替换为真实配乐、环境音素材和角色配音文件。

## 分镜节奏

1. 凌晨工位：用空办公室、待办、房租和语音消息表现大城市疲惫的“因”。
2. 雨夜离开：主角从城市高架和公交站离开，形成返乡决定的“果”。
3. 回乡路：用长途车驶入山谷的画面表现城市到乡村的空间变化。
4. 村口下车：主角从长途车下车，拖着行李沿村口小路走进小满村。
5. 村边小路：从村口自然过渡到竹林、河谷和村内道路。
6. 小满村：村广播引出春耕互助和县城集市。
7. 旧院子：邻居登场，建立情感落点。
8. 灶台余温：用老屋物件承接家庭记忆。
9. 春一日：落到第一天任务，进入可玩状态。

## 后续可扩展

- 加入角色立绘、口型/眨眼帧、对白头像。
- 加入轻量音效：雨声、车站广播、鸟鸣、开门声。
- 把字幕配置抽成 JSON，接入微信小游戏剧情播放器。
- 制作跳过后奖励/任务触发逻辑，例如自动接取“村委会报到”。

# 即梦视频生成素材与提示词

用途：把《小满村》“都市返乡”开场动画拆成适合即梦生成的 5 秒视频片段。

建议设置：

- 模式：视频生成 / Seedance 2.0。
- 比例：先用 16:9 720P 做横版概念片；后续微信小游戏开场再改 9:16 竖版。
- 时长：每条 5 秒。
- 参考：开启全能参考，按下方顺序上传图片。
- 字幕：不建议让即梦直接生成字幕，后期在剪映或游戏内对白系统叠加。

## 剪辑顺序建议

正式开场可以先做 6 条，每条 5 秒，总长约 30 秒：

1. 城市雨夜离开。
2. 长途车驶向乡村。
3. 地图式转场。
4. 抵达小满村。
5. 旧院子重新点亮。
6. 老屋与第一天任务。

集市和庙会两条更适合放在宣传片、玩法预告或新手引导后半段，不建议塞进第一版开场里。

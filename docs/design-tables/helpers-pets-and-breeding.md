# 宠物、帮工与动物繁育设计

## 设计目标

宠物、帮工和动物繁育用于补足小院经营的陪伴感、长期成长和地方特色。它们不应变成纯自动化挂机系统，而应服务三个体验：

- 小院更像一个有生活气的地方。
- 玩家能通过照料和选择形成自己的农场风格。
- 中国乡村的地方品种、邻里互助和熟人关系能进入玩法。

## 系统定位

| 系统 | 主要作用 | 解锁阶段 | 设计边界 |
| --- | --- | --- | --- |
| 宠物 | 陪伴、轻量辅助、情绪反馈 | 新手第 3 到 7 天 | 不直接产出大量资源 |
| 帮工 | 减少重复劳动、强化 NPC 关系 | 第一季中段 | 需要消耗人情或工资 |
| 动物繁育 | 长线养殖、地方品种、稀有产物 | 鸡鸭棚稳定后 | 不做复杂遗传模拟 |
| 地方品种 | 区域辨识度、收藏、节日评比 | 中期 | 不以真实地理品牌侵权命名 |

### 宠物获得方式

- 外婆送养。
- 村民委托后领养。
- 节日活动奖励。
- 好友推荐领养。
- 县城宠物救助事件。

### 宠物日常

| 行为 | 消耗 | 反馈 |
| --- | --- | --- |
| 喂食 | 宠物粮或普通食材 | 好感增加 |
| 抚摸 | 每日次数 | 心情提高 |
| 玩耍 | 少量时间 | 触发表情和小动画 |
| 洗澡 | 道具或现金 | 外观干净，节日互动 |
| 跟随 | 无 | 出门陪伴，不影响操作 |

### 宠物好感

| 等级 | 解锁 |
| ---: | --- |
| 1 | 回应玩家呼唤 |
| 2 | 跟随玩家在小院移动 |
| 3 | 早晨带来小提示 |
| 4 | 触发宠物小剧情 |
| 5 | 获得专属外观或窝棚装饰 |

### 宠物能力边界

- 宠物只提供提示、小概率发现、情绪加成和少量便利。
- 宠物不应自动收获大面积作物。
- 宠物不能影响排行榜核心成绩。
- 宠物能力可爱但不强制，避免玩家觉得不养就亏。

## 帮工系统

### 设计定位

帮工不是抽卡角色，而是村民关系、邻里互助和小院规模扩大后的自然结果。玩家通过好感、工资、人情值或任务邀请 NPC 短期帮忙。

## 动物繁育系统

### 设计原则

- 繁育要简单清楚，避免做成复杂遗传学。
- 稀有品种通过照料、环境、任务和少量随机产生。
- 地方品种提供外观、产物、图鉴和节日评比价值。
- 繁育不能无限复制高价值动物，需要时间、空间和饲料限制。

### 繁育流程

1. 建造或升级对应棚舍。
2. 拥有一对成熟动物，或通过村民借配。
3. 保持连续照料和健康状态。
4. 使用普通饲料或特色饲料。
5. 等待孕育或孵化周期。
6. 获得幼崽。
7. 幼崽成长后进入产出或图鉴。

## 体验风险

| 风险 | 应对 |
| --- | --- |
| 自动化过强，玩家无事可做 | 帮工只降低重复劳动，不完全替代核心行为 |
| 稀有繁育太肝 | 通过任务保底、活动兑换和图鉴奖励缓解 |
| 宠物能力变成必选 | 宠物只给轻量便利和情绪反馈 |
| 动物数量膨胀 | 棚舍容量、饲料、照料时间限制 |
| 真实地方品种命名风险 | 使用虚构小满村地方品种 |

## MVP 建议

MVP 不需要完整繁育系统，只做轻量版本：

- 宠物：小黄狗或狸花猫 1 只。
- 帮工：外婆提醒、周木匠修缮、梁建国打包 3 个功能。
- 动物：土鸡和麻鸭。
- 繁育：鸡蛋孵化为小鸡，周期 5 天。
- 地方品种：竹林土鸡 1 个支线品种。

## 首发建议

首发可以扩展到：

- 5 类宠物。
- 8 到 10 名可帮工 NPC。
- 鸡、鸭、鹅、羊、鱼塘、蜂箱。
- 6 到 10 个地方品种。
- 2 到 3 个动物评比活动。
- 宠物好感和动物图鉴。

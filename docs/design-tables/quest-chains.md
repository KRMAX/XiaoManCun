# 任务链表

## 任务设计原则

任务系统要把农场、加工、钓鱼、挖矿、社交、地图和集市串成自然目标。任务不应只是提交物品，还应承担教学、情绪铺垫、地图解锁和经济引导。

## 任务验收规则

- 主线任务必须至少解锁一个系统、地图、角色关系或长期目标。
- NPC 支线必须让玩家更理解角色，而不只是送东西。
- 日常委托用于消耗库存和引导地图，不应强制刷稀有物。
- 节日任务必须提前给玩家备货提示。
- 任务奖励应包含现金以外的内容，例如配方、地图、折扣、装饰、好感、声望。

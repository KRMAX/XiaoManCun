# 矿区层级和材料表

## 设计目标

挖矿系统为工具升级、建筑修缮、加工设备、摊位组件和村庄建设提供材料。题材上保持现实乡村语境，矿区包装为废弃采石场、老矿洞、旧砖瓦窑和山体旧洞。

## 平衡备注

- 前 20 层主要让玩家理解挖矿和建筑材料关系，不放高压风险。
- 21 到 50 层必须能稳定产出工具升级材料。
- 51 层以后再加入更强探索感和稀有收藏。
- 稀有材料不要成为早期主线卡点，避免玩家反复刷矿感到疲劳。

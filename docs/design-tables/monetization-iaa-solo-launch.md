# 个人主体 IAA 首发版变现方案

## 文档定位

`monetization-and-liveops.md` 是**企业主体 + 内购（IAP）+ 广告**的完整商业化方案。本文件在其基础上拆出一个**个人主体首发版**：

- 个人主体**无法开通虚拟支付（内购）**，只能用**广告变现（IAA = In-App Advertising）**。
- 目标：在「没有内购」的约束下，把原方案的付费点合理改造成广告点或玩法解锁点，**不破坏小满村的慢生活与公平交易**。
- 适用阶段：个人主体首发；未来若升级企业主体 + 版号，再叠加内购（见末尾「升级到企业版」）。

## 总原则

1. **广告是唯一收入来源**，但仍坚持 `monetization-and-liveops.md` 的边界：不卖数值、不破坏经济、不强插打断。
2. 所有广告**玩家自愿触发**，每个广告位有**每日次数上限**，广告奖励**不能成为最优解**。
3. 原本卖「外观」的内购，改为**通过玩法 / 活动 / 集市积分解锁**——外观本来就不含数值，免费化不伤平衡，反而促活跃和留存（利好广告曝光）。
4. 原本卖「便利/加速」的内购，改为**看激励视频获取**，且保留上限。

## 内购点改造对照表

| 原内购商品（企业版） | 个人 IAA 版改造 | 说明 |
| --- | --- | --- |
| 小院月卡 | **每日签到 + 每日 1 次「看广告领月卡同款福利」** | 用激励视频替代月卡的每日小福利，自愿领取 |
| 节气通行证 | **免费节气活动任务线**，奖励照发（限定装饰/头像框/配方） | 外观靠完成活动解锁，不收费；广告作为加速/补领入口 |
| 小院装饰包 | **玩法 + 集市积分 + 活动解锁** | 外观不卖数值，改为成就/积分兑换 |
| 摊位装饰包 | **集市积分兑换 + 排行榜奖励** | 鼓励多摆摊，正向循环 |
| 服装包 | **活动 / 成就 / 节日限定解锁** | 社交展示靠玩，不靠买 |
| 新手支持包 | **新手免费礼包**（首登直接给）+ 可选看广告再领一份 | 不跳过核心体验 |
| 付费货币「装饰券」 | **改为活动/玩法货币**（不可付费购买） | 个人版无内购，装饰券只通过活动获取，或直接并入集市积分 |

> 结论：**外观类全部免费化**（靠玩法/活动/积分解锁），**便利类全部广告化**（看激励视频，带上限）。这样既符合个人主体规则，又强化了「肝就有、不肝也能玩」的慢生活体验。

## 激励视频设计（核心收入位）

沿用 `monetization-and-liveops.md` 的广告表并适度强化，但严格控制体验。每个广告位都要满足：**自愿触发 + 明确奖励 + 每日上限 + 不破坏核心循环**。

| 广告位 | 触发场景 | 奖励 | 每日上限 | 体验保护 |
| --- | --- | --- | --- | --- |
| 每日小卖部福利 | 主动点小卖部「看广告领」 | 随机种子/肥料/小额现金 | 3 次 | 不影响主线，纯加成 |
| 加工加速 | 加工坊剩余时间页 | 缩短剩余时间 30% | 每项目每日 1 次 | 不允许无限跳过 |
| 体力小饭盒 | 体力不足提示处 | 恢复少量体力 | 2 次 | 不替代料理系统 |
| 集市吆喝 | 开摊后「吆喝」按钮 | 本场客流 +5% | 每场 1 次 | 与好友吆喝共享叠加上限 |
| 订单刷新 | 订单板「刷新」 | 刷新普通订单 | 2 次 | 稀有订单不靠广告 |
| 离线收益翻倍 | 上线领离线收益时 | 双倍部分离线收益（封顶） | 1 次 | 服务端算、设上限 |
| 月卡同款福利 | 每日签到页 | 现金/肥料/装饰币小包 | 1 次 | 替代原月卡的每日福利 |
| 复活/补签（谨慎） | 节日小游戏失败 / 漏签到 | 再来一次 / 补签 | 1 次 | 仅限非核心、非排行榜场景 |

设计要点：

- **激励视频为主**，因为它单次 eCPM 高、玩家接受度好、与「领奖励」心智一致。
- 奖励要「锦上添花」，绝不「不看就玩不下去」。
- 广告失败不发奖、成功只发一次（**服务端幂等**，见 `tech-data-qa.md`）。

## 插屏 / Banner 广告（谨慎）

| 类型 | 建议 | 说明 |
| --- | --- | --- |
| 插屏广告 | **仅放自然停顿点**：睡觉结算页之后、退出二级面板时，频率上限（如每日 ≤ 3 次、间隔 ≥ 几分钟） | 绝不在操作/剧情中强插 |
| Banner 横幅 | **不建议**在游戏场景内常驻 | 像素横屏占屏严重，伤体验；如用只放纯文本菜单页 |
| 原生模板广告 | 可放在背包/商店列表的非核心位 | 控制密度 |

> 个人 IAA 版没有内购兜底，容易冲动堆广告。**克制**比短期收入更重要——留存上去了，广告总收入才大。

## 收入预估思路（IAA）

粗略公式（仅供规划，非承诺）：

```
日广告收入 ≈ DAU × 人均激励视频次数 × 激励视频填充率 × eCPM / 1000
```

- 撬动收入的关键变量是 **DAU**（要靠留存 + 社交裂变）和 **人均看广告次数**（靠广告位设计的吸引力）。
- 个人主体广告收入由平台**代扣 20% 个税**（见上线清单）。
- 因此个人版的运营重心是：**做高留存 + 做高自愿广告渗透率**，而不是堆广告密度。

## 升级到企业版（未来内购并存）

数据验证 OK、决定做内购时，以下广告点可叠加/并存内购，无需推翻设计：

| 广告点 | 未来内购并存方案 |
| --- | --- |
| 月卡同款福利（广告领） | 恢复真正的「小院月卡」内购，广告版作为免费替代继续保留 |
| 节气活动（免费解锁） | 叠加「节气通行证」付费档（更多限定外观），免费线不动 |
| 装饰/服装（积分解锁） | 上架「装饰券」内购档，同时保留积分兑换 |
| 加工加速等便利广告 | 保持广告免费，不强行内购化（避免 pay-to-skip 观感） |

> 升级路径见 `wechat-release-process.md` 与 `solo-developer-launch-checklist.md`：注册个体户/企业 + 版号，或找发行商联运。

## 合规与体验注意事项

- 广告必须由玩家**主动触发**，不在剧情或关键操作中强插。
- 广告奖励有上限，**不能成为最优玩法**。
- 排行榜不受广告影响（吆喝广告有叠加上限，不破坏 `monetization-and-liveops.md` 的口碑榜/丰收榜逻辑）。
- 未成年人与广告相关限制遵守微信平台要求。
- 活动不强制长时间在线，保护慢生活节奏。

## 验收清单（IAA 首发版）

- [ ] 不看广告的玩家能完整体验主线和核心系统。
- [ ] 所有广告自愿触发、有每日上限、奖励为加成而非必需。
- [ ] 外观类全部可通过玩法/活动/积分免费获得，无付费墙。
- [ ] 便利类广告（加速/体力/翻倍）均服务端校验、幂等发奖、封顶。
- [ ] 无 Banner 常驻、插屏只在自然停顿点且限频。
- [ ] 排行榜不被广告碾压。
- [ ] 设计保留「升级企业版加内购」的扩展点，不需推翻。

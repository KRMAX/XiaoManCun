# 技术、数据埋点与 QA 设计

## 设计目标

本文件用于补齐从设计到开发落地的边界：哪些数据需要服务端校验，哪些系统需要埋点，哪些流程必须测试。它不是完整技术方案，但可以作为研发评估和测试用例拆分的基础。

## 客户端与服务端边界

| 系统 | 客户端负责 | 服务端负责 | 备注 |
| --- | --- | --- | --- |
| 农场操作 | 表现、操作反馈、临时状态 | 关键收益校验、跨天结算 | 防止改本地时间刷收益 |
| 背包仓库 | UI、排序、筛选 | 库存最终状态 | 交易相关必须服务端确认 |
| 集市摆摊 | 配置、预览、动画 | 成交、价格、收益、排行榜 | 核心经济 |
| 好友交易 | 访问展示、互动表现 | 库存扣减、收益、次数限制 | 防刷重点 |
| 订单系统 | 任务展示、提交入口 | 订单生成、提交校验 | 限时订单需校时 |
| 离线收益 | 展示和动画 | 离线时长、收益计算 | 设置上限 |
| 付费广告 | 展示入口 | 发奖、订单记录 | 需防重复领奖 |
| NPC 和剧情 | 对话表现、本地缓存 | 关键进度、奖励 | 分支选择要入档 |

## 反作弊重点

| 风险 | 处理 |
| --- | --- |
| 修改本地时间刷作物 | 服务端时间为准，离线收益封顶 |
| 修改库存 | 关键库存服务端校验 |
| 好友互刷交易 | 次数、价格、IP/设备/关系异常检测 |
| 广告重复领奖 | 服务端发奖幂等 |
| 排行榜刷分 | 异常收益、异常交易、异常在线时长过滤 |
| 内购伪造 | 平台订单校验 |

## QA 测试范围

### 农场

- 播种后跨天成长是否正确。
- 未浇水是否停止成长或降品质。
- 多季作物在换季时是否正确处理。
- 收获后品质、数量、经验是否正确。
- 背包满时收获是否有兜底。

### 钓鱼

- 不同天气和时间鱼类刷新是否正确。
- 新手鱼难度是否可完成。
- 鱼饵消耗和加成是否正确。
- 稀有鱼失败是否正确结算。
- 图鉴是否记录最大尺寸。

### 挖矿

- 层级掉落是否符合配置。
- 体力耗尽是否正确送回。
- 工具等级限制是否生效。
- 矿洞每日刷新是否正确。
- 背包满时矿物处理是否正确。

### 集市

- 上架扣库存或锁库存是否正确。
- 定价影响成交率是否正确。
- 天气、主题、摊位等级倍率是否生效。
- 好友购买是否扣库存并发收益。
- 滞销商品是否返回或保留。

### 任务和 NPC

- 前置任务未完成时不会误触发。
- NPC 行程随天气和节日改变。
- 好感奖励不会重复领取。
- 剧情选择正确写入存档。
- 任务物品不可误售或有二次确认。

### 付费和广告

- 广告失败不发奖。
- 广告成功只发一次奖。
- 月卡跨天发放正确。
- 内购到账和补单正确。
- 未成年人或平台限制按要求处理。

## 发布前检查

| 类型 | 检查项 |
| --- | --- |
| 性能 | 首屏加载、地图切换、低端机帧率 |
| 兼容 | 不同屏幕比例、安全区、微信版本 |
| 数据 | 配置表缺失、ID 重复、非法引用 |
| 内容 | 敏感词、错别字、伪文字、NPC 台词 |
| 经济 | 货币产出和消耗是否闭环 |
| 社交 | 好友数据、分享、排行榜 |
| 合规 | 广告、内购、隐私、未成年限制 |
| 兜底 | 断网、重连、重复点击、异常退出 |

## 灰度发布建议

- 第一批灰度只开放前 7 天内容和普通赶集。
- 重点观察新手漏斗、经济产出、卡任务点和崩溃率。
- 灰度期间降低付费入口存在感，先验证核心体验。
- 每日查看异常库存、异常货币和排行榜极值。
- 重大数值调整需要兼容老玩家存档。

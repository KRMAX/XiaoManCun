# 集市价格和客流数值模型

## 设计目标

集市是《小满村》的核心差异点。它既是经济出口，也是社交场景、节日场景和好友异步互动入口。数值模型要让玩家感觉“备货、定价、装饰、吆喝、节日匹配”都会影响结果。

## 集市类型

| market_id | 集市 | 开放 | 主卖品类 | 客流基准 | 价格波动 | 备注 |
| --- | --- | --- | --- | ---: | ---: | --- |
| market_regular | 普通赶集 | 每周二/周五 | 生鲜、基础加工品 | 100 | 1.00 | 稳定收入 |
| market_night | 夜市 | 夏季每周六，后续常驻 | 小吃、饮品、小游戏 | 130 | 1.10 | 夜间高客流 |
| market_harvest | 丰收集 | 秋季节日 | 大作物、粮食、干货 | 160 | 1.20 | 评比活动 |
| market_temple | 庙会 | 特定节日 | 手作、糕点、灯笼 | 180 | 1.25 | 民俗任务 |
| market_newyear | 年集 | 冬季末 | 年货、腊味、礼盒 | 220 | 1.40 | 高收益高备货 |
| market_county_big | 县城大集 | 月度/赛季 | 全品类 | 250 | 1.30 | 排行榜和好友交易 |

## 售价公式

```text
成交单价 = 基础售价
  x 品质倍率
  x 季节需求倍率
  x 集市主题倍率
  x 包装倍率
  x 摊位品牌倍率
  x 价格合理度修正
```

```text
成交数量 = 上架数量
  x min(1, 客流 / 需求竞争值)
  x 商品匹配度
  x 价格接受率
  x 摊位吸引力
```

## 价格合理度修正

玩家可在建议价基础上调价。调价影响利润和成交率。

| 定价区间 | 单价修正 | 成交率修正 | 玩家感受 |
| --- | ---: | ---: | --- |
| 低于建议价 30% | 0.70 | 1.50 | 卖得快但赚得少 |
| 低于建议价 10% | 0.90 | 1.20 | 稳妥促销 |
| 建议价 | 1.00 | 1.00 | 标准 |
| 高于建议价 10% | 1.10 | 0.85 | 精品可用 |
| 高于建议价 30% | 1.30 | 0.50 | 需要品牌和高品质 |
| 高于建议价 60% | 1.60 | 0.20 | 容易滞销 |

## 结算示例

### 普通赶集卖青菜

```text
小青菜基础售价 25
良品倍率 1.25
春季需求 1.10
普通赶集主题 1.05
无包装 1.00
竹木摊品牌 1.00
建议价出售

成交单价 = 25 x 1.25 x 1.10 x 1.05 = 36
```

### 年集卖年货礼盒

```text
年货礼盒基础售价 180
精品倍率 1.60
冬季需求 1.80
年集主题 1.80
节日礼盒 1.50
品牌摊 1.10
高价 10%，成交率 0.85

成交单价 = 180 x 1.60 x 1.80 x 1.80 x 1.50 x 1.10 x 1.10 = 1693
```

## 好友交易限制

| 限制 | 建议 |
| --- | --- |
| 每日购买次数 | 每好友 3 到 5 次 |
| 高价值物品 | 每日全局购买上限 |
| 交易税 | 高于基础售价部分收取 5% 到 10% |
| 价格范围 | 好友交易价格限制在建议价 70% 到 150% |
| 结算 | 服务端校验库存、货币、订单状态 |
| 留言 | 使用预设短句，减少审核风险 |

## 反通胀手段

- 建筑、工具、包装、村庄建设形成长期消耗。
- 节日高收益需要提前备货，不能每天刷。
- 高价礼盒消耗多种材料和加工时间。
- 好友交易有次数、价格和税费限制。
- 稀有物不能无限上架，部分只允许订单提交或收藏。

# 作物数值表

## 数值设计目标

作物系统承担早期教学、稳定经济、加工原料、集市备货和 NPC 礼物五类功能。前期作物要让玩家每天都有事做，中后期作物要通过季节、品质、加工和订单形成差异。

## 作物字段

| 字段 | 说明 |
| --- | --- |
| crop_id | 作物唯一 ID |
| 名称 | 玩家可见名称 |
| 季节 | 可种植季节 |
| 成长天数 | 从播种到首次收获 |
| 阶段 | 美术生长阶段数量 |
| 复收 | 是否多次收获 |
| 种子价 | 购买种子的现金成本 |
| 基础售价 | 普通品质直接出售价格 |
| 日均利润 | 粗略用于平衡，不含加工 |
| 需水 | 是否每天浇水 |
| 主要用途 | 出售、加工、料理、订单、礼物 |
| 解锁 | 初始、供销社等级、地图、剧情或节日 |

## 平衡备注

- 新手作物日均利润控制在 3 到 6，保证玩家能快速理解回本。
- 中期作物日均利润控制在 6 到 12，但需要更长成长或地图解锁。
- 复收作物前期投入高，适合培养季节规划意识。
- 加工利润应明显高于直接售卖，但受加工时间、设备和包装材料限制。
- 节日作物可短期高收益，但必须有备货压力和错过成本。

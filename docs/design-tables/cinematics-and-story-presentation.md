# 过场动画与剧情演出设计

## 设计目标

《小满村》需要过场动画，但不应该做成频繁打断玩家的长剧情游戏。微信小游戏的核心使用场景是碎片时间、好友分享和短时经营，因此剧情演出要服务情绪、节奏和系统解锁，而不是压过农场经营。

本项目推荐采用：

- 少量关键过场动画。
- 多个短镜头章节转场。
- 大量轻量剧情演出。
- 可跳过、可回看、可降级播放。

## 演出原则

| 原则 | 说明 |
| --- | --- |
| 短 | 单段剧情尽量控制在 10 到 30 秒，开场动画可稍长 |
| 可跳过 | 所有非交互过场都必须可跳过 |
| 可回看 | 关键剧情进入回忆录或地方志 |
| 轻资产 | 优先用分层插画、镜头移动、角色表情、音效和文字 |
| 不打断 | 日常经营中不频繁强制弹出长剧情 |
| 有触发意义 | 每段演出应对应情绪、系统解锁、地图解锁或人物关系变化 |

## 演出类型

| 类型 | 时长 | 使用场景 | 制作方式 | 优先级 |
| --- | ---: | --- | --- | --- |
| 开场动画 | 45 到 90 秒 | 首次进入游戏 | 分层插画 + 镜头 + 少量角色动作 | 最高 |
| 章节转场 | 10 到 20 秒 | 解锁新章、新地图、新系统 | 场景镜头 + 字幕 + 音效 | 高 |
| 节日开场 | 8 到 15 秒 | 夜市、庙会、丰收集、年集 | 场景换装 + 灯光 + 人群音效 | 高 |
| NPC 好感事件 | 20 到 60 秒 | 核心 NPC 支线 | 立绘表情 + 场景小演出 + 对话 | 高 |
| 系统解锁演出 | 5 到 10 秒 | 加工坊、快递站、矿洞等解锁 | 建筑修复动画或 UI 动画 | 中 |
| 日常小演出 | 3 到 8 秒 | 宠物、动物、收获、订单完成 | 小动画 + 音效 | 中 |
| 结局/季末演出 | 30 到 90 秒 | 年集、主线阶段收束 | 插画组 + 音乐 + 回忆镜头 | 高 |

## 开场动画分镜

### 叙事目标

开场要让玩家在 1 分钟左右理解三件事：

1. 玩家为什么离开城市。
2. 玩家为什么回到小满村。
3. 玩家接下来要亲手修复老院和村庄。

### 分镜表

| 镜头 | 时长 | 画面 | 音效/音乐 | 文案或台词 |
| --- | ---: | --- | --- | --- |
| 1 | 5 秒 | 城市夜晚，高楼灯光，办公室窗边的玩家 | 键盘声、远处车流 | 这一年，好像总是在赶路。 |
| 2 | 5 秒 | 地铁车厢，玩家低头看手机 | 地铁报站声 | 屏幕亮起，外婆来电。 |
| 3 | 8 秒 | 电话另一端是小满村老院，外婆坐在门口 | 电话电流声渐弱 | 外婆：有空就回来看看，院里的草都比人高了。 |
| 4 | 6 秒 | 玩家收拾行李，出租屋灯灭 | 拉链声、雨声 | 玩家没有立刻回答，但第二天买了票。 |
| 5 | 8 秒 | 高铁、县城车站、大巴驶向乡间 | 车轮声、广播声 | 城市越来越远，山和田越来越近。 |
| 6 | 8 秒 | 车窗外出现河道、竹林、晒谷场和村口小卖部 | 鸟鸣、风声 | 小满村还是那个小满村，又好像不一样了。 |
| 7 | 8 秒 | 老院门打开，杂草、旧水缸、破棚子入镜 | 木门声 | 玩家：这里真的还能住人吗？ |
| 8 | 8 秒 | 外婆端着热粥走出来 | 温暖音乐进入 | 外婆：回来了就好，先吃饭。 |
| 9 | 6 秒 | 玩家拿起锄头，看向第一块荒地 | 锄头落地声 | 从这一小块地开始吧。 |
| 10 | 4 秒 | 镜头落到可操作地块，UI 淡入 | 音乐转入游戏主旋律 | 进入新手操作。 |

## 开场动画制作建议

| 项目 | 建议 |
| --- | --- |
| 画面 | 6 到 10 张分层插画，不做完整视频 |
| 动画 | 镜头推拉、横移、前景遮罩、灯光变化 |
| 角色 | 少量眨眼、呼吸、转头、拿起锄头 |
| 文案 | 每屏不超过 18 个字 |
| 配音 | 可后置，不作为 MVP 必需 |
| 字幕 | 必须支持静音情况下理解剧情 |
| 跳过 | 第一次播放 3 秒后显示跳过 |
| 回看 | 家屋“旧相册”或“回忆录”中可重播 |

## 章节转场设计

章节转场用于告诉玩家“村子进入了新阶段”。不需要每章都做重动画，但关键系统解锁要有短演出。

| 章节 | 触发 | 演出内容 | 解锁 |
| --- | --- | --- | --- |
| 第一章：回到小满村 | 开场结束 | 老院清晨，外婆打开院门 | 小院 |
| 第二章：第一批收成 | 首次收获 | 菜筐装满，外婆笑着称重 | 日常委托 |
| 第三章：第一次赶集 | 集市开放 | 县城街口摊位展开，人声渐起 | 县城集市 |
| 第四章：修复老设施 | 村庄建设第一次完成 | 河堤或加工坊修复前后对比 | 村庄声望 |
| 第五章：村里的分歧 | 开发商登场 | 村民会，桌上摊开规划图 | 商业冲突线 |
| 第六章：四季生意 | 第一个节日活动 | 夜市灯串亮起或丰收晒场铺开 | 节日循环 |
| 第七章：小满品牌 | 第一批礼盒发货 | 快递车驶出村口 | 电商订单 |
| 第八章：村庄复兴 | 公共设施基本完成 | 村口、老小学、集市、人群剪影 | 终章 |

## NPC 好感事件演出

### 结构模板

```text
进入地点
  -> 镜头聚焦 NPC
  -> 发现问题或情绪
  -> 玩家选择或提交物品
  -> NPC 反应
  -> 关系变化或系统奖励
```

### 演出规格

| 层级 | 时长 | 内容 |
| --- | ---: | --- |
| 好感 1 | 10 到 20 秒 | 认识角色，说明功能 |
| 好感 3 | 30 到 45 秒 | 展示个人困境 |
| 好感 5 | 45 到 60 秒 | 关键选择或人物转折 |
| 好感 6 | 60 到 90 秒 | 人物线收束，可给专属插图 |

### 示例事件

| NPC | 事件 | 演出重点 |
| --- | --- | --- |
| 外婆 | 柜子里的旧照片 | 家屋旧物、家庭记忆、外婆不愿多说 |
| 阿禾 | 直播翻车 | 手机弹幕、村民误解、玩家陪她重新拍 |
| 小雨 | 等电话 | 老小学黄昏、无人接听、玩家陪伴 |
| 周木匠 | 木头说话 | 木匠铺、旧工具、手艺传承 |
| 梁建国 | 快递爆仓 | 包裹堆满驿站、好友订单引入 |
| 林书记 | 村民会 | 村庄建设分歧、公共利益选择 |

## 节日演出设计

节日演出的目标是让玩家一进场就感觉“今天的小满村不一样”。

| 节日 | 开场演出 | 场景变化 | 音效 |
| --- | --- | --- | --- |
| 春耕小集 | 村口摆出种子摊，油菜花摇动 | 春色、旗帜、农具摊 | 风声、叫卖声 |
| 夏夜市 | 灯串一盏盏亮起，摊位冒热气 | 夜色、灯笼、小吃摊 | 人群、锅铲、虫鸣 |
| 丰收集 | 晒谷场铺满粮食，南瓜摆上台 | 金黄、稻谷、评比台 | 锣声、笑声 |
| 庙会 | 戏台开锣，手作摊展开 | 红布、灯笼、戏台 | 锣鼓、戏曲片段 |
| 年集 | 雪或冷风中年货街亮起 | 春联、年糕、腊味、红灯笼 | 爆竹替代音、叫卖声 |

## 轻量剧情演出方式

### 推荐组合

- 背景场景图。
- 角色立绘或小人动作。
- 表情差分。
- 镜头推拉。
- 对话框。
- 环境音效。
- 少量粒子，例如雨、雪、灯光、落叶。

### 不推荐首发大量使用

- 长视频。
- 大量逐帧动画。
- 复杂 3D 过场。
- 不可跳过剧情。
- 每个普通任务都做专属演出。

## 可跳过与可回看

| 功能 | 要求 |
| --- | --- |
| 跳过 | 所有过场均可跳过，首次播放 3 秒后显示 |
| 快进 | 对话演出支持长按快进 |
| 自动播放 | 对话支持自动播放开关 |
| 回看 | 主线和核心 NPC 事件进入回忆录 |
| 剧情摘要 | 跳过后显示 1 到 2 句摘要 |
| 奖励发放 | 跳过不影响奖励、解锁和任务状态 |

## 回忆录系统

回忆录可以放在家屋室内，例如旧相册、外婆的柜子或村志本。

| 分类 | 内容 |
| --- | --- |
| 主线回忆 | 开场、章节转场、村庄重大事件 |
| 村民故事 | 核心 NPC 好感事件 |
| 节日留影 | 夜市、庙会、年集、丰收集 |
| 小院变化 | 老院修复前后 |
| 重要选择 | 与开发、村庄建设、人物关系相关的选择 |

## 包体和性能策略

微信小游戏需要控制首包体积和加载时间。剧情演出建议采用可复用资源。

| 资源 | 策略 |
| --- | --- |
| 分层插画 | 首包只放开场必要资源，其余分包加载 |
| 角色立绘 | 核心 NPC 共用表情模板 |
| 音频 | 短音效优先，长音乐循环复用 |
| 粒子 | 雨雪灯光使用程序化效果 |
| 字幕 | 文本配置化，便于审核和修改 |
| 节日资源 | 活动前预加载或分包下载 |

## 制作等级

| 等级 | 适用 | 制作内容 |
| --- | --- | --- |
| S 级 | 开场、年集、终章 | 分层插画、音乐、镜头、角色动作 |
| A 级 | 章节转场、核心 NPC 高好感事件 | 场景演出、立绘表情、音效 |
| B 级 | 系统解锁、普通 NPC 事件 | 对话、轻镜头、少量小动画 |
| C 级 | 日常委托、小提示 | 对话气泡、UI 动效 |

## MVP 演出清单

MVP 阶段建议只做必要演出。

| 演出 | 等级 | 说明 |
| --- | --- | --- |
| 开场回村 | S | 必做，建立题材和情绪 |
| 第一次播种 | C | UI 和小院反馈 |
| 第一批收成 | B | 菜筐、外婆台词 |
| 加工坊修复 | B | 修复前后对比 |
| 第一次快递订单 | B | 包裹、驿站、发货提示 |
| 第一次赶集 | A | 县城集市开场 |
| 外婆好感 1 | B | 旧照片或饭桌 |
| 夜市或年集预告 | A | 首个节日活动 |

## 首发演出清单

首发阶段建议补到：

- 完整开场动画。
- 8 个章节转场。
- 24 个核心 NPC 每人至少 2 段好感事件。
- 4 个季节代表节日开场。
- 小院、供销社、快递站、河堤、老小学等设施修复演出。
- 年集或丰收集的季末收束演出。
- 回忆录系统。

## 文案和声音规范

### 文案

- 字句短，适合移动端阅读。
- 不用大段旁白解释世界观。
- 关键情绪交给画面、停顿和声音。
- 台词要像村民说话，不像系统说明。

### 声音

- 城市段：键盘、车流、地铁、手机震动。
- 回村段：车轮、风、鸟鸣、犬吠、远处人声。
- 小院段：锄头、浇水、锅碗、木门、虫鸣。
- 集市段：叫卖、人群、三轮车、袋子摩擦、秤声。
- 节日段：锣鼓、灯串电流、锅铲、热闹但不刺耳的人声。

## 剧情触发规则

| 触发 | 说明 |
| --- | --- |
| 首次进入 | 播放开场 |
| 系统解锁 | 播放短转场 |
| 地图首次到达 | 播放 3 到 8 秒环境镜头 |
| NPC 好感达标 | 触发个人事件 |
| 节日前一天 | 播放预告或 NPC 提醒 |
| 节日当天首次进入 | 播放节日开场 |
| 重大选择后 | 播放结果反馈 |

## QA 检查

- 跳过剧情后任务状态正确。
- 回看剧情不重复发奖励。
- 断线或退出后不会卡在过场中。
- 静音状态下字幕足以理解剧情。
- 低端机播放过场不卡顿。
- 分包资源缺失时有降级方案。
- 剧情文本可被配置和审核。
- 章节转场不会在玩家高频操作中突然打断。

## 结论

《小满村》需要过场动画，尤其需要一个有记忆点的开场回村动画。但制作策略应是“关键节点精做，日常剧情轻演出”。这样既能建立题材情绪，也不会牺牲微信小游戏最重要的短时、顺滑和可反复打开的体验。

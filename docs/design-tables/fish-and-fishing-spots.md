# 鱼类和钓鱼点表

## 设计目标

钓鱼系统服务三个体验：短时放松、图鉴收集、订单和料理材料。它需要和季节、天气、时间、地图解锁以及鱼竿成长绑定。

## 钓鱼难度参数

| 难度 | 鱼行为 | 推荐鱼竿 | 操作要求 |
| ---: | --- | --- | --- |
| 1 | 几乎不挣扎 | 竹竿 | 点击收竿即可 |
| 2 | 轻微上下游动 | 竹竿 | 短按稳定 |
| 3 | 中等挣扎 | 普通鱼竿 | 需要控制进度 |
| 4 | 多次冲刺 | 普通鱼竿以上 | 需要鱼饵辅助 |
| 5 | 长距离冲刺 | 碳素鱼竿 | 熟练操作 |
| 6 | 高频变向 | 高级手作鱼竿 | 高级图鉴挑战 |

## 鱼竿与鱼饵

| 道具 | 解锁 | 效果 |
| --- | --- | --- |
| 竹竿 | 初始任务 | 可钓难度 1 到 3 |
| 普通鱼竿 | 供销社 | 稳定条宽度 +10% |
| 碳素鱼竿 | 县城渔具店 | 收线速度 +15% |
| 手作高级鱼竿 | 木匠好感 | 稀有鱼逃脱率降低 |
| 米饭粒 | 初始 | 常见鱼咬钩率提高 |
| 蚯蚓 | 雨后采集 | 河道鱼咬钩率提高 |
| 面团饵 | 料理台 | 鲤鱼、草鱼概率提高 |
| 香饵 | 水库解锁 | 大型鱼概率提高 |
| 特制夜钓饵 | 夜市任务 | 夜钓鱼概率提高 |

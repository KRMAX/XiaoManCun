# 商业化与运营活动设计

## 设计原则

《小满村》的商业化不能破坏慢生活、长期经营和公平交易。付费点应优先放在装饰、便利、外观、季节通行证和轻度加速上，避免直接出售高额现金和核心稀有资源。

## 商业化边界

| 可以做 | 谨慎做 | 不建议做 |
| --- | --- | --- |
| 装饰、服装、摊位外观 | 体力恢复、加工加速 | 直接卖大量货币 |
| 月卡小福利 | 稀有种子礼包 | 付费限定强力作物 |
| 广告换小奖励 | 广告复活或补签 | 强制插屏打断操作 |
| 节日通行证 | 限时礼包 | 影响排行榜公平的付费加成 |

## 广告设计

| 场景 | 奖励 | 频率限制 | 备注 |
| --- | --- | --- | --- |
| 每日小卖部广告 | 随机种子、肥料、小额现金 | 每日 3 次 | 不影响主线 |
| 加工完成加速 | 缩短剩余时间 30% | 每设备每日 1 次 | 不允许无限跳过 |
| 体力小饭盒 | 恢复少量体力 | 每日 2 次 | 避免替代料理系统 |
| 集市吆喝广告 | 本场客流 +5% | 每场 1 次 | 和好友吆喝叠加上限 |
| 订单刷新 | 刷新普通订单 | 每日 2 次 | 稀有订单不靠广告刷 |
| 离线双倍小额 | 双倍部分离线收益 | 每日 1 次 | 设置收益上限 |

## 内购设计

| 商品 | 类型 | 内容 | 设计说明 |
| --- | --- | --- | --- |
| 小院月卡 | 月卡 | 每日少量现金、肥料、装饰币 | 稳定轻付费 |
| 节气通行证 | 赛季 | 节气任务、装饰、头像框、摊位皮肤 | 不卖强数值 |
| 小院装饰包 | 外观 | 瓦房皮肤、院门、灯串、花坛 | 个性化 |
| 摊位装饰包 | 外观 | 布棚、招牌、灯笼、货架皮肤 | 集市展示 |
| 服装包 | 外观 | 返乡青年、赶集装、节日装 | 社交展示 |
| 新手支持包 | 一次性 | 基础种子、肥料、少量现金 | 不跳过核心体验 |

## 付费货币

建议设置“装饰券”或“玉兰券”作为付费或活动货币，只用于外观和便利，不进入核心商品交易。

| 货币 | 来源 | 消耗 | 限制 |
| --- | --- | --- | --- |
| 现金 | 经营获得 | 种子、工具、建筑 | 核心经济 |
| 装饰券 | 付费、活动 | 外观、家具、摊位皮肤 | 不可交易 |
| 集市积分 | 摆摊获得 | 集市装饰、活动物品 | 赛季可部分保留 |
| 人情值 | NPC 和任务 | 剧情、配方、服务 | 不可付费直接购买 |

## 运营节奏

| 周期 | 活动 | 目标 |
| --- | --- | --- |
| 每日 | 日常委托、订单、免费小奖励 | 登录和短时活跃 |
| 每周 | 固定赶集、好友订单、周挑战 | 周留存 |
| 每月 | 县城大集、排行榜、主题装饰 | 中期目标 |
| 每季 | 四季作物、节气任务、通行证 | 内容更新 |
| 节日 | 年集、庙会、端午、中秋 | 传播和回流 |

## 首月运营计划

| 周次 | 主题 | 内容 | 目标 |
| --- | --- | --- | --- |
| 第 1 周 | 回到小满村 | 新手任务、第一次赶集、签到 | 提升 D1/D3 留存 |
| 第 2 周 | 春耕小集 | 油菜花、蜂蜜、春菜订单 | 建立周活动习惯 |
| 第 3 周 | 夜市预热 | 辣酱、河虾、灯串装饰 | 引出夜间玩法 |
| 第 4 周 | 县城大集 | 好友摊位、排行榜、主题礼盒 | 验证社交和付费 |

## 活动模板

### 节气活动

| 字段 | 内容 |
| --- | --- |
| 活动名 | 清明采青、立夏尝鲜、白露茶香 |
| 时长 | 3 到 7 天 |
| 核心行为 | 采集、种植、制作、摆摊 |
| 奖励 | 限定装饰、头像框、配方 |
| 付费点 | 装饰通行证，不影响核心数值 |

### 县城大集

| 字段 | 内容 |
| --- | --- |
| 活动周期 | 每月一次 |
| 核心行为 | 备货、摆摊、好友吆喝、排行榜 |
| 榜单 | 销售额榜、口碑榜、特色商品榜 |
| 防刷 | 好友购买上限、异常价格过滤 |
| 奖励 | 摊位外观、称号、集市积分 |

## 排行榜设计

排行榜需要避免纯付费碾压。

| 榜单 | 计算方式 | 防付费碾压 |
| --- | --- | --- |
| 销售额榜 | 本期集市真实成交额 | 设置商品品类池和交易上限 |
| 口碑榜 | 好评、合理定价、回头客 | 不直接看金额 |
| 丰收榜 | 单件作物重量和品质 | 受农业行为影响 |
| 人气摊位榜 | 好友吆喝、访问、点赞 | 每好友每日计一次 |

## 回流设计

| 流失时间 | 回流内容 |
| --- | --- |
| 1 到 3 天 | 外婆提醒、作物状态、离线收益 |
| 4 到 7 天 | 好友买过你的摊位、订单待领取 |
| 8 到 14 天 | 限时节气活动和回归礼包 |
| 15 天以上 | 老院整理奖励、回归任务链 |

## 合规和体验注意事项

- 广告必须由玩家主动触发，不在剧情或关键操作中强插。
- 付费礼包要标明内容，不使用误导性概率展示。
- 未成年人和支付相关限制需遵守微信小游戏平台要求。
- 排行榜和好友交易要有异常检测。
- 活动不要让玩家每天必须长时间在线，否则会破坏轻松体验。

## 验收清单

- 不付费玩家能完整体验主线和核心系统。
- 付费主要提升外观、便利和表达，不直接破坏经济。
- 广告奖励有上限，不能成为最优玩法。
- 首月运营能支撑 D1、D7、D30 目标。
- 节日活动能复用基础系统，避免每次重做。

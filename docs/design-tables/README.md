## 使用方式

- 原型阶段优先使用每张表的 MVP 条目。
- 垂直切片阶段补齐一个完整季节的作物、鱼、矿物、NPC 和任务。
- 首发阶段再扩展到四季、几十地图、上百 NPC 和完整节日循环。
- 所有 ID 命名应与 `design.md` 的内容生产规范保持一致。
